# Yaoundé Population Exposure to Low-Lying Areas Near Waterways

## Project Question

Which areas of Yaoundé contain the largest populations living in low-lying areas within 200 metres of a waterway?

## Project Overview

This project uses open geospatial data to identify areas where relatively low-lying terrain, proximity to waterways and population overlap. The analysis is intended as a screening approach to support further investigation of flood exposure and urban resilience. It does not attempt to predict flooding.

## Data

* **OpenStreetMap / Geofabrik** — Cameroon OSM data, used to identify Yaoundé and mapped waterways
* **WorldPop SRTM** — Cameroon elevation data at approximately 100 m resolution
* **WorldPop** — Cameroon population distribution for 2020 at approximately 100 m resolution
